# Legacy workflow contracts

This is the field/action/filter review supporting the active November15 parity audit. The258-entry inventory remains the navigation index. The contracts below identify what must survive in native storage, scoped commands and exported facts; route existence alone is insufficient. Final acceptance and artifact identities belong in [the audit ledger](legacy-parity-audit-20261115.md).

Shared PHP navigation/form/connection/lookup helpers are replaced by reusable JSP components and the owning Spring services. There is no arbitrary SQL/file proxy or execution of legacy authentication/database entrypoints. PHP presentation-only comparisons run in network-disabled containers with synthetic values. All retained exceptions above preserve current FCMS financial and authorization rules instead of reproducing unsafe source behavior.

D8 makes defaults and future-date validation use the same Tanzania business calendar as existing payment evidence and displayed instants, independently of the host timezone. UTC remains the storage policy for event/audit instants. Frozen-midnight/New-Year checks and full payment/reversal regressions establish this correction.
