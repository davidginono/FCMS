# Resource workflow and loading reference

The Microfinance skill used the [AWS finder animation](https://docs.aws.amazon.com/images/AWSEC2/latest/UserGuide/images/use-ec2-instance-type-finder-animation.gif) as a visual reference: stationary register tools while rows load, focused bounded forms, blue ancestor breadcrumbs, compact neutral controls, orange primary task actions and a resizable selected-resource pane. The animation establishes appearance/transitions, not server authorization, error handling, keyboard behavior or mobile correctness. No local screenshot/GIF or Windows directory is required to use this guidance.

- Use existing FCMS navigation and native destinations. Keep shell nodes connected during supported in-place updates; do not add another router or change sidebar startup policy as part of a component port.
- Filters, paging, sort and authorized detail panels preserve the live document and forms where the existing controller supports it. Native modified clicks/downloads and dirty-exit confirmation retain their owners.
- Loaders reflect actual pending work: roughly 16px for an inline value/select, 20px for table rows/sections and 32px for a larger chart/canvas. Keep headings/tools and unrelated ready sections visible. No artificial delays, global blur, labeled progress strip or fabricated percentages.
- Data-region spinners use localized accessible status names without explanatory visible copy. Text action buttons retain their label beside a spinner; icon-only buttons show a centered spinner. Match cleanup to the request, including cancellation, supersession and page exit.
- Keep original native nodes for recovery. An uncertain POST is never automatically replayed. Do not persist measured page content, financial data or form values in a layout cache; only bounded geometry where the existing implementation supports it.
- IDs remain native authorized blue links. Separate-window hints/icons appear only on actual separate-window destinations.
- Split panes start closed at every width and on restored navigation. Only Show details opens one; selection/saved geometry do not. Store size/placement only, keep a keyboard/pointer resize separator and narrow-screen fallback, and avoid duplicate financial actions or decorative tabs.

Check stale-response races, local retry, pending/ready transitions, page exit/restoration, native navigation, selection reset, split close/reopen/resizing, both languages, responsive widths and reduced motion using currently authorized tools. Do not claim browser checks when they were omitted.
